# Schedulerの家事別初期値更新（2026-10-25）

## 変更内容

1. 組み込み20件それぞれに `frequencyDaysByMode` と `windowRadiusDays` を必須指定し、負荷別の共通周期による初期値決定を廃止しました。値は [家事ガイドの設定表](housework-guide.md#家事別初期設定) のとおりです。
2. コンロ・五徳の日常清掃を `normal`、洗面台清掃を `light` に変更しました。コンロの日常手順からつけ置きを外し、頑固な汚れの清掃は別家事#17で扱います。
3. 食器洗い・日常シンク清掃・ワークトップ拭き・浴室の水滴取りは `everyday = true`、全頻度モード1日周期、期間幅0日、期間移動幅0日にしました。保存済みの個別周期は引き続き優先されます。
4. Schedulerと天気調整の「軽い家事は期間幅0日」という制約を解除しました。期間幅は家事の指定値を使い、負荷から変更しません。
5. 家事ごとの設定画面で、負荷にかかわらず期間幅0〜14日を保存できるようにしました。負荷の切り替えだけでは周期や期間幅を変更しません。空欄・小数・範囲外の幅は保存を拒否します。
6. 茶渋・コーヒー渋と水アカ除去には、周期が現行の予定管理用の暫定値である旨を追加し、個別設定画面にも表示します。条件型の自動判定はまだ実装していません。
7. 組み込みカタログversionを2から3へ更新しました。旧デフォルトと一致する値だけを項目・頻度モードごとに更新し、変更済みの値、個別周期の上書き、有効・無効、割り当て、完了履歴、周期の起点を保持します。家電AI由来の家事・保存済み家電説明は対象外です。
8. 初期値が変わる家事の生成済み予定を削除し、古い期間が残らないよう再生成します。設定の保存時にも期間を再生成する、既存mainの修正をローカル作業用コードへ反映しました。
9. ガイド冒頭に20件の設定表、負荷の判断基準、周期の根拠、移行方針を追加しました。各家事の参考元はURL表記にそろえました。
10. 既存の「軽い家事は常に1日の期間」という検証の期待値を、新しい個別期間の仕様に合わせました。

## 移行時の制約

旧版には「ユーザーが編集したか」を設定値とは別に記録する情報がありません。旧デフォルトと同じ値を明示的に保存した場合は、未変更の値と区別できません。`recommendedCycleDays` / `userIntervalDays` に保存された個別周期は、旧デフォルトと同じ値でもそのまま保持します。

移行はアプリのデータ初期化時にトランザクション内で一度だけ実行します。DBのスキーマversionとは別のカタログversionを更新するため、今回のためのテーブル追加はありません。
