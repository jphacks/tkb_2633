# 個人・グループの家事設定と連結ページの操作

設定の「家事ごとの設定」は個人用、参加中のグループ用の順に表示する。グループ詳細では選択したグループ用、個人用の順に表示する。退出・除名・承認待ちのグループは編集対象にしない。

個人設定はルートの個人用Planner bindingを使う。グループ設定は明示したUID・groupIdのWorkspaceへ保存し、表示中のWorkspaceを切り替えない。同じ家事IDでも保存先DBを混同しない。同名家事のホームでの共通化は維持し、個人の元設定は変更せず残す。受信側の権限検査を維持し、v2一般メンバーには名前・手順の編集を提供し、有効状態・周期は管理者に限定する。v2の有効状態は既存の1件コマンドを使い、カテゴリ操作を複数の独立した保存へ展開しない。

連結した個別設定は同じフォームを再利用する。保存先の人型アイコンと「個人用」または「グループ用・グループ名」を、上部の固定ヘッダーに1回表示する。見出しと分類の二段全体の中央へ揃え、下部の固定Backと自動保存・無効入力・保存失敗の保持を維持する。設定から開く履歴も個人または名前を指定したグループへ接続し、別グループの履歴を誤表示しない。

スイッチは共通の44pt高の配置領域を使い、ネイティブの描画サイズを固定せず中央へ置く。iOSの背景を別途塗る指定を除き、OFF時の二重描画を防ぐ。ONは落ち着いた青とし、カテゴリ・個別行のスイッチ、件数領域、矢印の列を揃える。

設定・説明の右端では、長い棒を分類、短い棒を各家事に対応させる。指で上下になぞると分類内の個々の家事へ移動できる。全体を1つのジェスチャー領域とし、近接した目盛りのタップ領域を重ねない。VoiceOver/TalkBack向けには前後の家事へ移動するadjustable操作を提供する。非常に多い家事では短い目盛りを間引いて描画し、移動先は全件保持する。仮想化した本文は引き続き最初の2章ずつ描画する。

推奨日前の家事は、濃くした薄灰色の背景と淡い青の「推奨日前」ラベルで区別する。完了後はこのラベルを外す。期限間近の黄系表示と完了後の並び順は保持する。

## 検証

- iOS条件2,249/2,249、Android条件2,249/2,249。失敗・skipなし。lint・型検査成功。
- ローカルFirestore Rules Emulator 71/71。元の341機能契約を保持し、347へ拡張。
- 実SQLiteで個人・v1グループの別保存とOutbox分離、選択していないグループの編集・履歴、アカウント・参加状態の変更拒否、v2の管理者制御と個人サービスを読まない設定取得を検査。
- 既存の保存・再読込失敗、入力保持、Back、完了・Undoのテストを維持。月末の天気検査は、翌月へ移った予定を実際に月移動して確認する。
- iOS 27シミュレーターで、両保存先の設定・固定ヘッダー・ON/OFF描画・長短の棒とドラッグによる家事への移動を確認。
- 接続中のiPhoneではXCTestによる実タップでホーム→ヘルプ→ホームを確認し、画面画像とも照合。端末データは初期化していない。この確認をAndroid実機や全画面の物理端末検証の代用とはしない。
