# 家事お知らせアプリ

生活スタイルに合わせて家事の予定を整え、「何を・いつ頃・どうやって行うか」を知らせるスマートフォンアプリです。

## 製品概要

家事の周期、実施期間、休日、負荷、家族の分担をもとに、無理のない家事スケジュールを作ります。家事の詳細、完了・未完了、履歴、ゴミ収集日をアプリ内で管理します。

### 必須要件

- ゴミ収集日を曜日ごとに登録し、通知する
- 家事の手順、注意事項、必要な道具を表示する
- 天気に応じて家事の実施タイミングを調整する
- 家事同士の依存関係を扱う
- 家事をまとめて実行できるスケジュールを生成する
- カレンダー形式で予定を表示する
- 完了・未完了と実施履歴を記録する
- 未完了の家事を踏まえてスケジュールを再調整する
- 家事のタイミングを通知する
- iOS・Androidのウィジェットに次の家事を表示する
- 部屋干し・外干しを考慮した洗濯計画を扱う
- 家族・同居人と家事を分担する

## 実装状況

現在はアプリと各機能をつなぐ土台を用意しています。画面、家事スケジューラ、天気による調整、家族間同期、AI解析などの具体的な動作は未実装です。

- 家事・世帯・履歴・予定などを端末内SQLiteに保存する初期スキーマ
- 曜日ごとのゴミ収集日を日付へ展開する処理
- ゴミ収集日の例外を後から追加するための接続口
- 天気予報とスケジュール調整ポリシーの接続口（調整は無効）
- AI解析の接続口（AI APIや資料取得処理は未接続）
- 端末内通知の汎用ゲートウェイ
- iOS・Androidの「次の家事」ウィジェットの登録枠
- オフライン利用後に同期できるようにするための世帯同期ゲートウェイ（同期先未接続）

## 開発技術

- Expo SDK 58、React Native、TypeScript
- Expo Router
- Expo SQLite
- Expo Notifications
- Expo Widgets（iOS・Android）

## 開発

```sh
npm ci
npx expo start
```

ウィジェットを含むネイティブ機能の確認には、Expo Goではなく開発ビルドを使用します。
