# カレンダーの表示改善とWeb版の提供終了

2026年10月26日。基準コミット: `eb73226`。最新mainから続けた修正です。

## 表示の修正

- 月を移動した際の「○月○日の予定を表示中」の横にあった、白い数字入りの青いバッジを削除。文章で選択日を示します。
- 本文、見出し、設定項目、補足、タブ、初期設定、家事・家電一覧と詳細、履歴の文字を拡大。共通本文は14→16pt、コンパクトボタンは13→15pt、補足は概ね14〜15ptにしました。ホームの「ゴミ曜日を管理」などのリンクは12→16ptです。
- 共通の小さなボタンと選択チップは高さ44以上とし、拡大した文字に余白を確保しました。
- カレンダーの日付は13→18pt、曜日は11→15pt、ゴミ名は8→12ptに拡大。長いゴミ名はカレンダー内のみ「容器プラ」などの短い表記を使い、読み上げと登録一覧では元の名称を維持します。
- 日付セルの最小高さを52とし、週の中で全セルを同じ高さまで伸ばします。隔週・毎月のゴミ名がある週でも、今日や選択日の背景が同じ高さで表示されます。ゴミ名がない週まで一律に縦長にはしません。
- 家事の点を直径4→6、横棒を14×3→18×4に拡大。0件で非表示、色の境界1〜5／6〜9／10以上、最大5点と色ごとの数え直しは維持しています。

## ゴミの色と非表示

- 標準32区分に、白地で読める別々の色を名称ごとに固定しました。可燃ごみは橙、びんは青緑、粗大ごみは紫などです。定義リストの順番、予定ID、曜日、周期が変わっても色は変えません。
- 表記ゆれと検索の別名も同じ色に統一します。例:「可燃ゴミ」「燃えるごみ」「可燃ごみ」、「ビン」「瓶」「びん」。独自のゴミ名には正規化した名称から一定の色を割り当てます。
- カレンダーの曜日・日付、登録フォーム、登録済み一覧、次の収集日、ホーム、初期設定で同じ色を使います。
- 毎週収集は曜日だけを囲み、通常の日付は囲みません。「今回は表示しない」にした、その収集日のみ灰色の枠と淡い灰色の背景を出します。再表示すると灰色枠は消えます。
- 隔週・毎月の非表示は日付ラベルを消します。毎週用の灰色枠は出しません。毎週の非表示と別の毎月収集が同日なら、灰色枠の中に有効な毎月収集名をその種類の色で残します。

## Web版の削除

作業中にユーザーから「Webはいらない、削除」と指定されたため、Web版を提供終了しました。

- Expoの対象をiOS・Androidに限定。Webの起動コマンド、出力設定、ブラウザ向けの分離ヘッダー、SQLiteのWebAssembly設定を削除。
- `react-dom`、`react-native-web`の直接依存と、Web専用のAPI停止処理・通知・ウィジェットの代替実装・CSS・バッジ・Web画像を削除。
- 画面、初期設定、更新処理からWeb専用の分岐と案内を除去。READMEの起動手順をiOS・Androidに変更。
- ローカルのWeb専用サーバー（8094）を停止。
- Expo Hostingの本番エイリアスと、過去の配信データ9件を削除。再照会で配信0件、エイリアス0件。本番URLはHTTP404で「一致する配信なし」、過去URLはHTTP500で「this worker has been deleted」を返し、アプリは配信されません。
- モバイルの家電AI処理、AIプロンプト、公式資料へのリンク、Google認証は継続します。これらが使用する外部サイト閲覧やGoogleのWeb client IDは、Web版アプリの公開機能とは別の処理です。
