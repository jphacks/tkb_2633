# ゴミ出し・ヘルプ・家電遷移の修正（2026-10-26）

## 対象

開始時の main: `1431827e2258a9121f84b9b50cfaada2f4f16aad`。
最新 main の既存作業用 worktree で修正。元のローカル checkout にある別の未コミット変更は対象外。

## 変更内容の全件

### 1. カレンダーのゴミ名

- カレンダーの曜日・日付内だけ「ごみ」「ゴミ」「ゴみ」「ごミ」を省略。「可燃」「粗大」などと表示。
- 種類ごとの色は元の名前で決めるため、省略しても色は変わらない。
- 登録名、検索候補、管理画面の一覧、収集周期は変更しない。
- 対象: `src/features/waste/type-appearance.ts`, `src/app/(tabs)/explore.tsx`。

### 2. ホームのゴミ出し

- 大きな青い「今日のゴミ収集」パネルを、家事と同じ白いカードに変更。
- 「今回だけ非表示」「曜日」を削除。種類名と「ゴミ出し」、右端の四角を表示。
- 四角を押すとその収集日だけホームから非表示。次回以降の予定・登録・家事の完了数には影響しない。
- 保存中は四角を無効化。再描画前の連打も防止。保存に失敗したときはカードを残して再試行できるようにした。
- 対象: `src/app/(tabs)/index.tsx`, 新規 `src/components/waste-occurrence-card.tsx`, `src/features/waste/use-waste-occurrence-toggle.tsx`。

### 3. カレンダー下のゴミ出しカード

- 選択日に収集がある場合、家事カードより上に表示。
- 家事カードより低く、名前は20pt、補助文は18pt、四角は24pt。家事の四角は28pt。
- 右端を同じ28pt幅の列に揃え、両方の四角の中心位置を統一。
- 「ゴミ出し非表示」と四角を表示。非表示の予定もチェック済みのカードとして残し、同じ場所で再表示できる。
- 毎週の非表示日の灰色枠、隔週・毎月の非表示日から名前と枠を消す既存動作を維持。
- 毎週・隔週・毎月を、選択した日付で計算。ホーム向けの取得期間の外の日付にも対応。
- 対象: `src/app/(tabs)/explore.tsx` と上記共通カード・操作。

### 4. 不要な説明文

- 分類内の「○○に分類されている家事です。」を削除し、検索欄を上へ詰めた。
- 設定の家事一覧の「有効／無効 · 周期や負荷を調整」を削除。
- 個別設定の「この家事の頻度や実施条件を調整できます。」を削除。
- 対象: `src/app/(tabs)/guide.tsx`, `src/app/settings.tsx`, `src/app/chores/[id].tsx`。個別設定の別ルートにも同じ画面が適用される。

### 5. ヘルプ

- 設定と同じ `AccordionSection` を使用。初期状態は見出しだけ、タップで開閉。
- 12項目へ拡充: ホーム、完了・取り消し、推奨日と実施期間、カレンダー操作、点・横棒・色、ゴミ収集、説明・豆知識、家電、周期設定、通知・ウィジェット、天気、Google連携。
- 色の境界1〜5／6〜9／10件以上、点の最大5個と色ごとの数え直し、0件時の非表示、チェック操作、薄いカード、期限超過3日、終了翌日の未完了のみ通知などを説明。
- 本文を画面ルートから `src/features/help/help-content.ts` へ分離。
- 対象: `src/app/help.tsx`, 新規 `src/features/help/help-content.ts`。

### 6. 家電の詳細表示と戻る動作

- `router.replace` による一覧への戻りを `router.dismissTo` に変更。家電一覧・家事一覧の両方の入口に対応。
- 戻り先が履歴に存在しない場合の置換にも戻るアニメーションを指定。通常の画面を開く方向は維持。
- 長い全お手入れ項目を一度に描画する `ScrollView + map` を `FlatList` に変更。初回1項目、追加描画も1項目ずつに分割。
- 再び画面を開いた際に既存本文を読み込み画面へ置き換えないようにした。
- 画面から離れた後に完了した読み込み結果を破棄。読み込み失敗を捕捉し、初回失敗時は再読み込み、再取得失敗時は既存本文を保持。
- 表示部品と手順カードをルート外の `src/features/appliance-care/appliance-detail-content.tsx` へ分離。
- 対象: 同新規ファイル、`src/app/(tabs)/manual/appliances/[id]/index.tsx`, `src/app/(tabs)/manual/appliance-care.tsx`, `src/app/(tabs)/manual/_layout.tsx`, `src/app/_layout.tsx`。

### 7. 天気・地域データのクレジット

実際の通信先は Open-Meteo Forecast API と Open-Meteo Geocoding API。

- 設定の最下部に「クレジット」を追加。
- Open-Meteo、GeoNames、CC BY 4.0へのリンク、地域候補の表示・洗濯日の調整に加工している旨を記載。
- 設定の天気欄・初期設定の地域検索にも提供元リンクを表示。ホームで天気調整を知らせる箇所にもOpen-Meteoリンクを追加。
- 外部リンクを開けなかった場合はエラーを表示。
- 対象: 新規 `src/components/data-credits.tsx`, `src/app/settings.tsx`, `src/features/onboarding/first-run-setup.tsx`, `src/app/(tabs)/index.tsx`。

確認した公式資料（2026-10-26）:

- https://open-meteo.com/en/licence — CC BY 4.0、提供元・ライセンスのリンク、加工の明示、表示箇所付近の出典リンク。
- https://open-meteo.com/en/docs/geocoding-api — 地域データの出典はGeoNames。
- https://www.geonames.org/export/ — GeoNamesへのリンク等による出典表示。
- https://docs.expo.dev/versions/v58.0.0/ と Expo Routerの同SDKリファレンス、Stack・navigation公式資料。
- https://reactnative.dev/docs/flatlist — 初回・追加描画の分割、リストのヘッダー、仮想化。
