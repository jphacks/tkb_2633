## 標準の作成・復旧

`sharingCreationProtocol()`は未指定時にv2を選び、明示的な`EXPO_PUBLIC_SHARING_V2_ENABLED=false`だけで新規作成を従来経路へ戻せる。既存グループを開くときは、従来どおり保存された署名付きの版を使う。家族／同居人は本人が選び、共有家事は無効から開始する。個人設定や履歴を自動で取り込まない。

`sharingOwnerRecoveryEnabled()`も既定をONとする。`EXPO_PUBLIC_SHARING_OWNER_RECOVERY=false`で、以前のRules配備向けに追加の復旧通信を停止できる。既存の所有者確認・最終確認・署名検証・元データ保持を省略しない。

機能契約は355件のまま、新規作成の旧「明示ON時だけv2」という参照を、今回の明示された標準v2の検査へ変更した。種別の明示選択、連打抑制、失敗時の入力保持、アカウント切替の保護、v1の回帰を残す。必須Cloud参照は51件。v1の8ソース契約と`liflow-shared-1`、v2の受信契約`liflow-shared-2-draft-38`は変更しない。
