# 家事の説明・豆知識まとめ

組み込み家事カタログ全20件の説明をまとめたガイドです。各項目の説明、目安時間、道具、手順、注意事項、豆知識、参考元を掲載しています。

## Scheduler用の負荷・周期・実施可能期間

このガイドの「負荷」は、掃除そのものの運動強度だけではなく、家事Plannerが同じ日に複数の家事を配置するときの負担を表します。目安時間、身体的負荷、準備・後片付け、分解やつけ置き、薬剤使用などの工程数を総合して判断します。

- **軽い（light）**：おおむね15分程度まで。準備が少なく、忙しい日にも入れやすい家事。
- **普通（normal）**：おおむね20〜35分程度、または複数工程を伴う家事。
- **重い（heavy）**：40分前後以上、または分解・複数箇所・強いこすり洗いなどを伴い、まとまった時間を確保したい家事。

**周期と負荷は独立して扱います。** 重い家事だから低頻度、軽い家事だから高頻度とは限りません。実施可能期間も負荷から決めず、家事ごとに指定します。

「±2日」は基準日から前後2日の計5日間です。推奨日はその期間内から負荷などを考慮して選びます。ここに示した期間幅は全頻度モードに共通する初期値で、家事ごとに変更できます。

### 日次固定として扱う家事

次の4件は `everyday = true`、全頻度モードの周期を1日、期間幅と期間移動幅を0日にします。個別に保存した周期は、頻度モードの初期値より優先されます。

| 家事 | 理由 |
| --- | --- |
| 食器を洗う | 使用後に発生する日常家事 |
| キッチンシンクを日常掃除する | 日々の水分・調理くず除去 |
| キッチンワークトップを拭く | 調理後の日常清掃 |
| 浴室の水滴取り・乾燥 | 入浴後の予防的手入れ |

### 重みづけの考え方

2024 Compendium of Physical Activitiesの家事の運動強度は、負荷を考える参考資料の一つです。ただし、このアプリの `load` は運動生理学上の強度そのものではなく、同じ日にまとめても現実的かを判断するための負荷です。

所要時間、身体的な作業量、準備・片付け、分解やつけ置き、洗剤・薬剤の扱い、複数箇所の移動を総合して決めます。頑固な汚れを#17へ分離した「コンロ・五徳の油汚れを掃除する」は `normal`、窓・浴室・レンジフード・ベランダは `heavy` とします。

### 周期の根拠の扱い

- **メーカー・清掃事業者が明示している周期**：浴室、レンジフード、コンロ、トイレ、洗面台、シンク、窓、ベランダなどは、明示的な頻度を標準値の中心にします。
- **生活条件によって変わる周期**：衣類洗濯、ほこり取りなどは、世帯人数、使用量、季節、住環境による差が大きいため、現実的な初期値として提示し、ユーザー変更を前提とします。
- **本来は条件型である家事**：#19の茶渋・コーヒー渋と#20の水アカ除去は、汚れが目立つ・残るときに実行します。固定周期の正しさを示すものではありません。現行Scheduler用の長めの暫定周期とし、将来は `asNeeded` のような条件型へ分離することを検討します。現時点で条件型の自動判定は行いません。

### 既存データの更新

組み込みカタログversion 3で、この表の初期値を反映します。各頻度モードの周期・負荷・期間幅・期間移動幅・休日優先・日次設定を旧デフォルトと個別に比較し、一致した値だけを更新します。個別周期の上書き、変更済みの値、有効・無効、完了履歴は保持します。旧版には編集の有無を別途記録する情報がないため、旧デフォルトと同じ値を明示的に保存した場合は、未変更の値と区別できません。

## 1. 浴室全体を掃除する

**カテゴリ:** 水回り　**目安時間:** 約40分

浴槽・壁・床を洗い、排水口のごみを取り除いて換気します。

### 用意する道具

- ゴム手袋
- やわらかいスポンジ
- 浴室用中性洗剤
- 浴室用ブラシ
- やわらかい布
- 必要に応じてカビ取り剤

### 手順

1. 浴室内の物を移動し、髪の毛や大きなゴミを取り除く。
2. 浴槽・壁・床の汚れをシャワーで流す。
3. 落ちない汚れには浴室用中性洗剤を使い、スポンジ等でやさしく洗う。
4. 排水口のゴミ受けなど、取り外して清掃できる部分の髪の毛や汚れを除く。
5. 洗剤が残らないよう十分にすすぐ。
6. できるだけ水滴を拭き取る。
7. 換気扇や窓を使って十分換気する。

### 注意事項

- 粗い研磨材や硬いタワシは素材を傷つける場合がある。
- カビ取り剤は製品表示に従い、使用中は十分換気する。
- 肩より高い位置へカビ取り剤を直接スプレーしない。
- 塩素系と酸性タイプの洗浄剤を混ぜない。

### 豆知識

#### 水滴を残さないだけでも違う

水アカは水分が乾燥を繰り返すことで蓄積しやすくなります。入浴・掃除後に壁や浴槽の水分を軽く取って換気すると、後の掃除が楽になります。LIXILも掃除後の水分の拭き取りを推奨しています。

**参考元:** [https://www.lixil.co.jp/support/clean/bathroom.htm](https://www.lixil.co.jp/support/clean/bathroom.htm)、[https://www.lixil.co.jp/support/manual/bathroom/ns-sp/care.htm](https://www.lixil.co.jp/support/manual/bathroom/ns-sp/care.htm)

## 2. レンジフード・換気扇を掃除する

**カテゴリ:** キッチン　**目安時間:** 約45分

電源を切り、取り外せる部品と本体の油汚れを掃除します。

### 用意する道具

- ゴム手袋
- 台所用中性洗剤
- スポンジ
- やわらかい布
- 歯ブラシ
- 洗い桶または袋

### 手順

1. 運転を止める。
2. 電源を切り、可能な機種では電源プラグを抜く。難しい場合は取扱説明書に従う。
3. フィルターやファンなど、取扱説明書で取り外し可能な部品を外す。
4. 本体表面の油汚れを、薄めた中性洗剤など機種指定の方法で拭き取る。
5. 取り外した部品の油汚れが強い場合は、取扱説明書で可能ならぬるま湯と中性洗剤につけ置きする。
6. スポンジや歯ブラシで汚れを落とす。
7. 十分すすぎ、完全に乾かす。
8. 部品を正しく取り付ける。

### 注意事項

- モーターやスイッチなどの電気部品へ水をかけない。
- 部品の端で手を切らないよう手袋を使用する。
- 分解方法と洗剤の種類は機種の説明書を優先する。

### 豆知識

#### 油汚れには少し温かい湯

冷えた油は落ちにくくなります。取り外し可能な部品について、メーカーが許可していれば35〜40℃程度のぬるま湯につけると油汚れをゆるめやすくなります。Panasonicは35〜40℃、LIXILは約40℃のつけ置きを紹介しています。

**参考元:** [https://www.lixil.co.jp/support/clean/kitchen_08_regular.htm](https://www.lixil.co.jp/support/clean/kitchen_08_regular.htm)、[https://sumai.panasonic.jp/support/care/kitchen/05/](https://sumai.panasonic.jp/support/care/kitchen/05/)

## 3. コンロ・五徳の油汚れを掃除する

**カテゴリ:** キッチン　**目安時間:** 約35分

冷えたコンロの五徳や受け皿、天板の油汚れを落とします。

### 用意する道具

- ゴム手袋
- 台所用中性洗剤
- やわらかいスポンジ
- 歯ブラシ
- 乾いた布

### 手順

1. 火を止め、十分に冷えるまで待つ。
2. 五徳や受け皿など、取り外せる部品を外す。
3. 軽い汚れはやわらかい布で水拭きする。
4. 落ちない場合は台所用中性洗剤を使う。
5. スポンジや歯ブラシで軽く汚れを落とす。
6. すすぎ、水気を拭き取る。
7. 十分乾燥させて元に戻す。

### 注意事項

- 加熱直後に触らない。
- 点火部などの扱いは製品の取扱説明書を優先する。
- 表面処理によって使用できる洗剤・道具が異なる。

### 豆知識

#### 外せない汚れには「湿布」という方法もある

LIXILでは、取り外せない五徳・受け皿の一部について、洗剤を含ませたキッチンペーパーを約15分貼る「湿布法」を紹介しています。機種・素材で使用可否が異なるため、説明書の確認が前提です。

**参考元:** [https://www.lixil.co.jp/support/clean/kitchen_06_daily.htm](https://www.lixil.co.jp/support/clean/kitchen_06_daily.htm)、[https://faq.lixil.co.jp/--626cd6ca906696001d03666a](https://faq.lixil.co.jp/--626cd6ca906696001d03666a)

## 4. 窓・サッシ・網戸を掃除する

**カテゴリ:** 居室　**目安時間:** 約45分

サッシの砂や網戸のほこりを取り、窓ガラスを拭き上げます。

### 用意する道具

- やわらかい布
- スポンジ
- 中性洗剤
- ブラシ
- 掃除機
- 必要に応じてスクイージー

### 手順

1. サッシ溝にある砂や大きなゴミを取り除く。
2. 網戸は構造に合った方法でやさしく水洗いまたは拭き掃除する。
3. ガラスを水拭きする。
4. 汚れが強い場合のみ、水で薄めた中性洗剤を使用する。
5. 洗剤を使った場合は十分取り除く。
6. ガラスを乾いたやわらかい布等で仕上げる。
7. サッシの残った汚れを取り除く。

### 注意事項

- ガラスを硬い道具でこすらない。
- 網戸を強く押さない。
- 網戸の取り外し可否は製品ごとに異なる。
- 高所や窓の外へ無理に身を乗り出さない。

### 豆知識

#### 網戸は強く押すより「支え方」が重要

取り外せるタイプの網戸では、LIXILが室内側を下にして平らに置いて洗う方法を案内しています。立てたまま強く押すと、網が緩んだり破れたりする場合があります。

**参考元:** [https://www.lixil.co.jp/support/clean/window_shutter_05.htm](https://www.lixil.co.jp/support/clean/window_shutter_05.htm)、[https://www.lixil.co.jp/support/clean/window_shutter_01.htm](https://www.lixil.co.jp/support/clean/window_shutter_01.htm)、[https://www.lixil.co.jp/lineup/window/amido/clean/](https://www.lixil.co.jp/lineup/window/amido/clean/)

## 5. ベランダ・バルコニーを掃除する

**カテゴリ:** 屋外　**目安時間:** 約40分

落ち葉や砂を回収し、排水口と手すりを掃除します。

### 用意する道具

- ほうき
- ちりとり
- ゴム手袋
- 雑巾
- 必要に応じてデッキブラシ

### 手順

1. 植木鉢や収納物など、移動できる物を移動する。
2. 落ち葉、砂、ほこりを先に掃き取る。
3. 排水口付近のゴミを取り除く。
4. 水を使用できる環境では、必要な部分だけ少量の水で濡らしてこすり洗いする。
5. 手すりは固く絞った布で拭く。
6. 排水口にゴミが残っていないことを確認する。

### 注意事項

- 集合住宅では管理規約と水を流せるかを確認する。
- 階下や隣室への水の飛散に注意する。
- 洗剤は床材や防水層に使用可能なものだけを使う。
- 室外機などの電気機器へ水をかけない。

### 豆知識

#### 晴天より曇りの日が掃除向きな場合がある

ダスキンは、湿度の高い曇りの日はほこりが飛び散りにくく、ベランダ掃除に向くとしています。強風の日は逆にほこりが飛びやすくなります。

#### 水を大量に使えない場所では濡れ新聞紙も使える

少量の水で湿らせた新聞紙を床にまき、ほうきで集めると、細かな砂ぼこりを吸着させながら回収できます。

**参考元:** [https://www.duskin.jp/merrymaids/column/detail/00031/](https://www.duskin.jp/merrymaids/column/detail/00031/)

## 6. トイレを掃除する

**カテゴリ:** 水回り　**目安時間:** 約20分

便器・便座・外側を洗い、床や壁の汚れを拭き取ります。

### 用意する道具

- ゴム手袋
- トイレ用ブラシ
- トイレ用中性洗剤
- 掃除用シートまたは布

### 手順

1. 床などの髪の毛やほこりを取り除く。
2. 温水洗浄便座・暖房便座の場合は、取扱説明書に従って電源を切る。
3. 便器内へトイレ用洗剤を使用する。
4. 内側、水際、フチまわり等をブラシで洗う。
5. 便座、便フタ、便器外側を拭く。
6. 床や壁の汚れも必要に応じて拭く。

### 注意事項

- 電気部品へ直接水をかけない。
- 酸性タイプと塩素系の洗浄剤を混ぜない。
- 便器や便座の材質に使用可能な洗剤を確認する。

### 豆知識

#### 水際の輪ジミには「洗剤パック」

LIXILでは便器内の水位を下げ、トイレットペーパーを汚れに貼り、トイレ用中性洗剤を含ませて約30分置いてからブラシで掃除する方法を紹介しています。便器の材質・洗剤の指定を確認してください。

**参考元:** [https://www.lixil.co.jp/support/clean/toilet_01_daily.htm](https://www.lixil.co.jp/support/clean/toilet_01_daily.htm)、[https://www.lixil.co.jp/support/clean/toilet_01_regular.htm](https://www.lixil.co.jp/support/clean/toilet_01_regular.htm)

## 7. 洗面台を掃除する

**カテゴリ:** 水回り　**目安時間:** 約15分

洗面ボウルや水栓まわりの汚れを落とし、水滴を拭き取ります。

### 用意する道具

- やわらかいスポンジ
- 中性洗剤
- やわらかい布
- 歯ブラシ

### 手順

1. 髪の毛などのゴミを取り除く。
2. 洗面ボウルを水またはぬるま湯で濡らす。
3. スポンジで汚れを落とす。
4. 落ちない場合は素材に使用可能な中性洗剤を使う。
5. 水栓まわりや継ぎ目を必要に応じてブラシで掃除する。
6. 洗剤を十分に流す。
7. 水滴を乾いた布で拭き取る。

### 注意事項

- 洗面ボウルやカウンターの素材によって使用可能な洗剤が異なる。
- 鏡は一般鏡、防曇加工鏡などで方法が異なるため、鏡の説明書を確認する。

### 豆知識

#### 水滴を拭くだけでも予防になる

洗面台は石けんカス、髪の毛、水分が残ることで汚れが蓄積しやすくなります。LIXILは使用後に汚れと水滴を拭き取ることを日常の基本としています。

**参考元:** [https://www.lixil.co.jp/support/clean/powderroom_04_daily.htm](https://www.lixil.co.jp/support/clean/powderroom_04_daily.htm)

## 8. フローリングを掃除する

**カテゴリ:** 居室　**目安時間:** 約25分

床のほこりを集めてから掃除機をかけ、必要な場合だけ水拭きします。

## 11. 食器を洗う

- 手洗い用台所洗剤
- やわらかいスポンジ
- 水切りかご

### 手順

1. 食べ残しを取り除く。
2. 強い油汚れは、可能なら紙などで先に取り除く。
3. 油汚れの少ない食器から洗う。
4. 食器用洗剤とスポンジで洗う。

- 漆器、木製品、金銀装飾品等は扱いが異なる。

### 豆知識

#### 茶渋・コーヒー渋は普通にこすり続けなくてもいい

カップや湯飲みについた茶渋・コーヒー渋について、花王は台所用塩素系漂白剤による漂白を案内しています。食器の素材を確認し、製品表示どおりの濃度・時間を守って十分すすぎます。金銀装飾や漆器など使用できない素材には使わず、酸性タイプの洗剤と混ぜないでください。製品の取扱説明書で使用可能なら、ステンレス水筒の茶渋に泡タイプ漂白剤を使う方法も案内されています。

#### 油汚れは先に紙で取ると楽

油をそのままスポンジへ移すより、先に取り除いてから「油の少ない食器→油の多い食器」の順に洗うと、スポンジや洗剤を汚しにくくなります。

LIXILでは一部シンクの水アカ除去にクエン酸水を案内していますが、素材・コーティングにより方法が異なります。使用前にシンクの説明書を確認してください。クエン酸は酸性なので塩素系漂白剤と併用しないでください。

## 17. 五徳・受け皿のこびりつき汚れ掃除

**カテゴリ:** キッチン　**目安時間:** 約30分

通常の水拭きでは取れない五徳や受け皿の油・吹きこぼれ汚れを落とします。

### 用意する道具

- ゴム手袋
- 台所用中性洗剤
- キッチンペーパー
- やわらかい布
- やわらかいスポンジ
- 歯ブラシ
- 取り外せる場合は洗い桶または大きめの袋

### 取り外せる部品

1. コンロを使用していないことを確認し、五徳や受け皿が十分に冷えるまで待つ。
2. 取り外し可能な五徳や受け皿を外す。
3. 約40℃の湯へ台所用中性洗剤を入れる。
4. 五徳や受け皿をつけ、汚れを浮かせる。
5. やわらかいスポンジや歯ブラシで残った汚れを落とす。
6. 洗剤を十分洗い流す。
7. 乾いた布で水分を取り、十分乾燥させて元に戻す。

1. 十分に冷えていることを確認する。
2. 汚れている場所へキッチンペーパーをかぶせる。
3. 台所用中性洗剤を使い、ペーパーを汚れへ密着させる。
4. 約15分置く。
5. ペーパーで汚れを拭き取る。
6. 水拭きして洗剤を除去する。
7. 最後に乾拭きする。

### 注意事項

- 加熱直後は触らない。
- コンロの種類によって部品構造や清掃方法が異なる。
- 点火装置や電気部品へ水や洗剤をかけない。
- 使用できる洗剤について取扱説明書を確認する。

### 豆知識

#### 取り外せない場所は洗剤を含ませたペーパーで

取り外せない場所まで無理につけ置きする必要はありません。液体を流し込む代わりに、洗剤を含ませたペーパーを汚れへ密着させるのが湿布法の発想です。

## 20. キッチンシンクの水アカ除去

**カテゴリ:** キッチン　**目安時間:** 約25分

普段の中性洗剤では落ちにくくなった、白っぽい水アカを除去します。

### 用意する道具

- ゴム手袋
- やわらかい布
- スポンジ
- シンクの素材に使用可能な水アカ用洗剤
- 素材によってはクエン酸水
- 必要に応じてキッチンペーパー
- 歯ブラシ

### 手順

1. シンクの材質・コーティングを確認する。
2. 最初に台所用中性洗剤とやわらかいスポンジで通常の汚れを落とす。
3. それでも白い水アカが残る場合、素材に使用できる水アカ用洗剤を使用する。
4. クエン酸を使用できる素材の場合は、クエン酸水を吹き付け、やわらかい布で拭く。
5. 落ちにくい場合は、素材の説明書で問題なければキッチンペーパー等を使って洗剤を汚れへ密着させる。
6. 歯ブラシ等、素材に使用可能な道具でやさしく汚れを落とす。
7. 洗剤を十分洗い流す、または十分に水拭きする。
8. 最後に水分を拭き取る。

### 注意事項

- シンクの素材・コーティングによってクエン酸、クレンザー、メラミンスポンジ等を使用できない場合がある。
- 必ず製品の取扱説明書を優先する。
- クエン酸は酸性なので、塩素系漂白剤と同時に使用しない。
- 洗剤分を残さない。
